Cómo se genera este log

  1. El navegador envía la acción al gateway por HTTP (por ejemplo POST /api/votos).
  2. El gateway toma la IP y el navegador (cabecera User-Agent), asigna una traza y procesa la petición en el clúster por RMI.
  3. Cuando tiene el resultado, agrega una línea en el archivo usuarios.log con la hora, la acción, el resultado y los datos de la persona (cédula enmascarada).
  4. Publica la misma acción como evento USUARIO, que llega a esta pantalla por WebSocket en tiempo real.
